# 经典强化学习
本书大部分内容都在介绍强化学习的理论，这里暂且称为经典强化学习。随着强化学习能解决越来越复杂的任务（如围棋），经典强化学习求解难度越来越大，此时开始引入深度学习来求解。

## 强化学习要解决的问题
经典强化学习理论其实不复杂，用本书中吃苹果的例子（GridWorld）来解释：如下图所示，智能体在左下角，现在要训练智能体吃到苹果，同时避免吃到炸弹。
![[attachments/Pasted image 20261013225605.png|362]]

**目标：强化学习的最终目标就是：对每一个格子，算出一个"最优动作"，也就是站在这格该往哪走，才能让长期累积收益最大。**

**问题的设定**
- 每走一步，奖励 **-0.04**（或 0）
- 走到 +1 格：奖励 +1，回合结束
- 走到 -1 格：奖励 -1，回合结束
- 中间那堵墙不能走
- 动作：上下左右
**目标不是"每一步拿最多奖励"，而是"从起点走到 +1、且尽量少绕路"。**

## 马尔可夫决策过程

马尔可夫决策过程（MDP）就是**给强化学习问题建立的标准数学框架**。
如下图所示：
- **它由五元组构成**：状态 S、动作 A、转移概率 P、奖励 R、折扣 γ。
- **核心假设是马尔可夫性**：下一步只取决于当前状态和动作，与更早的历史无关。
- **它描述的是一个交互循环**：在状态 s 做动作 a → 环境给奖励 r、转到新状态 s' → 再决策。
- **它要解决的问题**：在这个过程里找到一个策略 π，让长期累积奖励最大。
- **Q 学习、TD、MC 等方法，本质上都是在 MDP 框架下求解最优策略的不同算法。**
下图中过程可以简化为序列：
$$
S_t,A_t,R_t,S_{t+1},A_{t+1},R_{t+1}....
$$
从当前到未来的总收益就是这些 $R_t$ 之和。但是为了避免收益爆炸，会用一个折扣系数降低未来收益的权重
![[attachments/Pasted image 20261013230558.png|316]]
### 贪婪跟探索
上面计算收益之和的时候，会出现一种情况，考虑下表的两种情况：
- 对于收益1，虽然总和收益更大，但是走第三步时带来的损失。
- 对于收益2总和收益虽然更小，但是每一步都是正收益。
如果训练的时候都是倾向于贪心算法（每一步都走收益最大的），那么模型就会走收益2。从而错过更好的收益1。因此训练的过程中也会引入探索，给模型一些发现更好路线的机会

| 收益1 | 1   | 1   | -2  | 10  |
| --- | --- | --- | --- | --- |
| 收益2 | 1   | 1   | 1   | 1   |

## 贝尔曼方程
贝尔曼方程是强化学习的数学基础，看起来很复杂，实际就是一个递推/自举方程，核心公式为：
$$V(s) = \mathbb{E}\big[r + \gamma V(s')\big]$$
其中$s'$为下一次的状态
**价值之间的自洽关系**：当前状态的价值，等于即时奖励加上未来价值的折扣期望。
### 直接用贝尔曼方程求解
几乎没有实际问题能用贝尔曼方程直接求解，主要问题有两个：
1. 有无限个状态（例如机器人走路），对应贝尔曼方程就是无限个，显然无法求解
2. 状态有限，但太多无法计算，例如围棋

对于书中3x4网格问题实际是可以用贝尔曼方程求解的（需要12个方程）
计算时**把贝尔曼方程写成线性方程组**：
对每个状态 s 列一个方程：
$$V(s) = \sum_a \pi(a|s)\sum_{s'} P(s'|s,a)\big[R + \gamma V(s')\big]$$
如果状态有 N 个，就有 **N 个方程、N 个未知数**，可以用矩阵直接解：
$$V = R + \gamma P V \quad\Rightarrow\quad V = (I - \gamma P)^{-1} R$$
### 无限状态时怎么办

- **函数逼近**：用网络代替表格（深度强化学习），参数有限，状态无限也能学
- **采样**：MC、TD 不去枚举所有状态，而是**走到的状态才更新**
- **只更新访问过的状态**：没到过的状态暂时不管

## 求解办法
前面提到了对很多问题不能用贝尔曼方程求解，其实还有很多其他方法求解。这里对应书中介绍的几种经典求解方法。
先总结下这几种方法的本质区别：

| 方法          | 更新目标用什么                  | 要不要环境模型<br>知道 P(s'\|s,a) 和 R | 要不要等回合结束 |
| ----------- | ------------------------ | ---------------------------- | -------- |
| 动态规划 DP     | 用**已知模型**算期望             | **要**                        | 不用（自举）   |
| 蒙特卡洛 MC     | 用**实际走完的真实回报**           | 不要                           | **要**    |
| TD 算法       | 用**走一步 + 自举估计**          | 不要                           | 不用       |
| Q 学习（TD 特例） | TD 的一种（off-policy + max） | 不要                           | 不用       |
三种算法区别（偏置、方差角度）：

|     | 偏置  | 方差  | 原因              | 备注       |
| --- | --- | --- | --------------- | -------- |
| MC  | 无偏  | 高   | 用真实回报，但一条轨迹随机性大 | 样本要够多才行  |
| TD  | 有偏  | 低   | 自举引入偏差，但只看一步    |          |
| DP  | 有偏  | 最低  | 直接求期望，但依赖模型正确   | 自举过程是有偏的 |
### 动态规划 DP
动态规划这个名字起的不是很好，简单来说动态规划就是：**最优子结构 + 重叠子问题**（关于动态规划可以参考 [[../computer/《数学之美》读书笔记|《数学之美》读书笔记]] 中介绍的用动态规划做导航问题，从这里看，导航问题也可以归为强化学习问题）
它的前提是：
1. **最优子结构**：大问题的最优解，能由小问题的最优解拼出来
2. **重叠子问题**：同一个小问题会被反复用到

**在强化学习里，贝尔曼方程天然就是"最优子结构"：状态 s 的价值，由后继状态 s' 的价值决定**
$$V(s) = \mathbb{E}\big[r + \gamma V(s')\big]$$
**前提：知道环境模型（有格子问题的地图）**：知道在 s 做 a 会以多大概率到哪个 s'、拿多少奖励
**DP 的做法是（参考下式）：**
- 先假定 V(s') 已知（或上一轮的估计）
- 用它去更新 V(s)
- 反复迭代，直到所有 V 收敛
$$V(s) \leftarrow \sum_{a} \pi(a|s) \sum_{s'} P(s'|s,a)\big[R + \gamma V(s')\big]$$
**特点：** 拿到地图，直接算出来
- 对所有可能的下一个状态**求期望**，不是采样（蒙特卡罗是采样）
- **自举**（用 V(s') 更新 V(s)）
- 缺点：真实问题几乎拿不到模型（不知道确切的概率），且状态多时算不动
### 蒙特卡洛 MC
DP需要知道真实环境才能计算（对于一些电子游戏是可以的，但实际问题不太行）。
如果没有真实环境相关的知识，就没法知道：
**在状态s，执行动作a，有多大的概率得到s'**
这就造成没法计算每一步的收益。这个时候就需要蒙特卡洛模拟。简单说，蒙特卡洛就是随机试，试的次数多了，真实的分布就出来的。

**前提**：不需要模型，但要**和环境交互**（要试出来分布），而且**必须走完整个回合**。
**更新式**: 直观描述: 用 估计出来的价值 $V(t)$ 跟试出来的 $G_t$ 之间的差值 来更新估计，为了稳定，需要一个学习率 $\alpha$
$$V(s) \leftarrow V(s) + \alpha\big[G_t - V(s)\big]$$
其中 $G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots$ 是**从这一步到回合结束的真实累积回报**。
**特点：** 亲自走完，看真实结果
- 目标是**真实值**，不是估计 → **无偏**
- 但必须等回合结束才能算 $G_t$
- 方差大（一整条轨迹的随机性全进来了）
- 只能用于**有终点的回合制任务**
### TD 算法
蒙特卡罗模拟虽然可以应对缺少环境相关知识的问题，但是从当前一直积累到结束这个要求还是太强了，一是计算量很大，而是很多问题没有结束时刻。
改进算法就是TD算法，他不需要等回合结束，走一步就更新（也有多步的）

**前提**：不需要模型，**不用等回合结束**，走一步就能更新。
**更新式（TD(0)）：**
$$
V(s) \leftarrow V(s) + \alpha\big[\underbrace{r + \gamma V(s')}_{\text{TD 目标}} - V(s)\big]
$$
**特点：**
- 用**走一步的真实奖励 r + 对下一步的估计 V(s')** 当目标
- **自举** → 有偏，但方差小
- 每步都能学，在线学习
- 是 MC 和 DP 的折中
### Q 学习（TD 特例）

Q 学习是 **TD 的一个特例**，专门学**动作价值 Q(s,a)**，而且是 **off-policy**（行为策略跟目标策略不同）：
$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]$$
参考上面的更新公式，**特殊点在于 max**
- 更新时假设**下一步永远选最优动作**
- 所以它学的是**最优策略**的价值，哪怕当前行为策略是在乱走

对比 **SARSA**（on-policy 的 TD 控制）：
$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma Q(s',a') - Q(s,a)\big]$$
SARSA 用**实际下一步动作**的 Q，Q 学习用**最大**的 Q。区别就在这。

# Q学习+神经网络（DQN）
开头先明确下：**DQN实际让网络学的价值函数，至于怎么行动，实际是从价值函数进一步推导出来的，跟前面的经典强化学习方法一致。** 后续介绍的策略梯度法则是直接训练网络给出策略，是不同的方法。
## Q学习到DQN
回顾Q学习的公式
$$Q’(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]$$
用 $T$ 替换 $r+\gamma\text{max}_{a'} Q(s',a')$ 得到：
$$Q'(s,a) \leftarrow Q(s,a) + \alpha\big[T - Q(s,a)\big]$$
这个公式跟神经网络的训练形式一致：
- $T$ 是真值
- $\alpha$ 是学习率
这样就可以用圣经网络来代替Q函数，其他地方跟 经典Q学习一样（甚至代码不需要怎么改）就可以用网络来搞了。
## 网络看起来只看到了下一步？
前面介绍TD算法，他的一个主要特点就是只看下一步，但是我们网络训练的目标是预测**从当前开始到未来所有的价值**。
看起来训练的方法跟目标不一致？实际上**网络每次更新时只看一步。但"一步"里已经包含了"未来"的信息。**
TD 目标中 $max Q(s', a')$ 已经包含了网络以前学到的从 $s'$ 到未来的所有价值
$$y = r + \gamma \max_{a'} Q(s', a')$$
具体看下面的训练过程拆解会更直观。
## 训练过程拆解
### 任务
**走迷宫**：从起点到终点，到终点给 +1，其他每步给 0，折扣 γ=0.9。
### 准备阶段: 随机初始化，瞎猜
- Q 网络 $Q_θ$ 随机初始化，权重是随机数
- 此时对任何 (s,a)，输出的 Q 值都是**接近 0 的随机小噪声**
- 经验回放池（replay buffer）是空的
- 目标网络 $Q_θ⁻$$（如果有）复制自当前网络
### 1. 第一次选Action（随机）

当前网络基本就是随机输出，（输入状态$s_0$ 给网络，网络输出Q值），下一步根据Q值选动作（注意要**ε-贪心**，初期多探索、少贪心）。例如输出如下

```
Q(s₀, 上) = 0.03
Q(s₀, 下) = -0.01
Q(s₀, 左) = 0.07   ← 最大
Q(s₀, 右) = 0.02
```

### 2. 执行动作，观察结果

执行"左"，环境返回：
- 新状态 $s_1$
- 即时奖励 $r = 0$（没到终点）
- 是否结束 done = False
- replay buffer 记录 `(s₀, 左, r=0, s₁, done=False)`(即 transition)
多次调用网络，replay buffer 得到一系列记录
### 3. 从 buffer 采样，算 TD 目标
从 buffer 里随机抽一批（如 32 条）transition。对其中一条 `(s, a, r, s', done)`：
**如果没结束：**
$$y = r + \gamma \max_{a'} Q_{\theta^-}(s', a')$$
**如果结束了（到达终点，之后就没有了）：**
$$y = r$$
初期因为 r 几乎全是 0，且 Q 全是噪声，所以 **y ≈ 0 附近的一个小噪声**。
### 4. 算损失、反向传播、更新 θ
这一步终于可以更新网络了，目的就是让网络的输出与 当前状态下，当前行动得到的奖励靠。（当然这里的奖励也不一定是完全准确的，需要迭代自举中修正）
$$\text{Loss} = \big(y - Q_\theta(s,a)\big)^2$$
- $Q_θ(s,a)$ 是网络对"刚做的这个动作"的估计
- `y` 是"即时奖励 + 对未来的旧估计"
**但初期 y ≈ 0，而 Q_θ(s,a) 也 ≈ 0，所以 loss 极小，几乎学不动。**（此时没有信息源头，走到终点才会有信息源头）
### 5. 反复循环，直到撞到终点
每走一步就重复 1~4。因为几乎全随机，走了很多很多步后，**某一次运气好撞到终点**：
```
(s_k, 某动作, r=1, s_terminal, done=True)
```
这条数据放到 replay buffer。当它被采样到时：
$$y = 1 \quad (\text{因为 done=True})$$
于是网络第一次收到"这个动作价值是 1"的信号。**信息源头出现了。**
### 6. 奖励开始倒传（关键）
下一轮，某个状态 $s_{k-1}$ 的 transition 采样到，它的$s'$ 恰好是终点 $s_k$：
$$y = 0 + \gamma \max_{a'} Q(s_k, a') \approx 0.9 \times 1 = 0.9$$
于是 $s_{k-1}$ 的 Q 开始往 0.9 靠。
再下一轮，$s_{k-2}$ 看到 $s_{k-1}$ 的 $Q≈0.9$：
$$y \approx 0.9 \times 0.9 = 0.81$$
**价值像水波一样，从终点一圈圈往外扩散。** 离终点越近的状态，Q 值越早、越高地被点亮。
### 7. 继续训练
随着 Q 值扩散：
- 靠近终点的状态，正确动作的 Q 明显高于其他动作
- ε-贪心下，网络越来越多选到"对的动作"
- 走迷宫的平均步数下降，成功率上升
- 更多成功轨迹进 replay buffer，又加速价值传播 → **正反馈**

### 训练过程几个值得注意的细节
1. **"全随机"阶段可能极长**：状态空间越大、奖励越稀疏，这个阶段越长，甚至永远撞不到。
2. **不是撞到一次就学会**：要这条数据被采样到、且**传播多轮**，才见效。
3. **目标网络的作用**：如果每步都用最新的 $Q_θ$ 算 $y$，$y$ 和目标一起动，会震荡。用旧一点的 $Q_θ⁻$ 算 y，训练稳（$Q_\theta-$ 是 $Q_\theta$ 的副本，$Q_\theta$ 频繁更新，但是$Q_\theta-$ 间隔一段时间才同步，用于稳定训练）。
4. **replay buffer 的作用**：让"终点那条宝贵数据"能被反复采样，而不是用完就丢；同时打散相关性。
5. **ε 要衰减**：后期 ε 调小，从探索转向利用（后期贪心的作用更大，前期要多探索）。

# 策略梯度法

|      | Q 学习（值方法）           | 策略梯度（策略方法）        |
| ---- | ------------------- | ----------------- |
| 学什么  | 学 $Q(s,a)$ 或 $V(s)$ | **直接学策略 π(a\|s)** |
| 怎么决策 | 算出所有 Q，选最大的         | 网络直接输出动作概率，采样     |
| 策略哪来 | **隐式**：从 Q 值里推出来    | **显式**：网络本身就是策略   |

把策略写成一个带参数 θ 的函数：
$$\pi_\theta(a|s)$$
网络输入状态 $s$，输出**每个动作(action)的概率**：
```
π(上|s) = 0.1
π(下|s) = 0.6   ← 最可能选
π(左|s) = 0.2
π(右|s) = 0.1
```
然后**直接用梯度上升，让"能拿高回报的动作"概率变大**。

目标函数：**最大化期望回报**
$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\big[R(\tau)\big]$$
其中:
- $\tau$ 是一条完整轨迹，例如$(S_0,A_0,R_0,S_1,A_1,R_1,\dots,S_{T+1})$
- $R(\tau)$ 是这条轨迹的总回报。

直接对 $J(\theta)$ 求导(比较复杂，不展开)，结果：
$$\nabla_\theta J(\theta) = \mathbb{E}\Big[\nabla_\theta \log \pi_\theta(a|s) \cdot G_t\Big]$$
其中：
- $\nabla_\theta \log \pi_\theta(a|s)$：**让这个动作概率变大的方向**（log 避免调整幅度爆炸）
- $G_t$：**这个动作之后拿到的真实回报**
- 两者相乘 → **回报高，就往"增大该动作概率"的方向走；回报低，就往反方向走**：好动作，加概率；坏动作，减概率。

**对比Q学习**

|      | Q 学习            | 策略梯度            |
| ---- | --------------- | --------------- |
| 更新依据 | TD 误差（估计 vs 估计） | **真实回报 G_t**    |
| 偏置   | 有偏（自举）          | **无偏**（用真实回报）   |
| 方差   | 低               | **高**（整条轨迹的随机性） |
| 动作空间 | 离散方便，连续难        | **连续、高维都行**     |
| 随机策略 | 通常隐式贪心          | **天然支持随机策略**    |
## REINFORCE

REINFORCE 是最简单的策略梯度算法，流程：
```
1. 用当前 π_θ 跑完一整条轨迹（等到回合结束）
2. 记录每一步的 (s, a, G_t)
3. 对每步算 ∇log π_θ(a|s) · G_t
4. 梯度上升更新 θ
5. 重复
```
**缺点**
1. **方差极大**：用整条轨迹的真实回报 $G_t$，随机性大。
	- 引入基线（baseline）
	$$\nabla_\theta J = \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a|s) \cdot (G_t - b(s))\big]$$
	减去 $b(s)$（通常是 $V(s)$），**不改变期望（仍无偏），但大幅降方差**。看"比预期好多少"。
2. **样本效率低**: 一条轨迹只用一次就丢
	- Actor-Critic：
		- **Actor**：策略网络 $π_θ$（策略梯度更新）
		- **Critic**：价值网络 $V_w$（估计基线 / 优势）
