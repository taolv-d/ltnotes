# 经典强化学习
本书大部分内容都在介绍强化学习的理论，这里暂且称为经典强化学习。随着强化学习能解决越来越复杂的任务（如围棋），经典强化学习求解难度越来越大，此时开始引入深度学习来求解。

## 强化学习要解决的问题
经典强化学习理论其实不复杂，用本书中吃苹果的例子（GridWorld）来解释：如下图所示，智能体在左下角，现在要训练智能体吃到苹果，同时避免吃到炸弹。
![[attachments/Pasted image 20261013225605.png|455]]

**目标：强化学习的最终目标就是：对每一个格子，算出一个"最优动作"，也就是站在这格该往哪走，才能让长期累积收益最大。**

**问题的设定**
- 每走一步，奖励 **-0.04**（或 0）
- 走到 +1 格：奖励 +1，回合结束
- 走到 -1 格：奖励 -1，回合结束
- 中间那堵墙不能走
- 动作：上下左右
**目标不是"每一步拿最多奖励"，而是"从起点走到 +1、且尽量少绕路"。**

## 马尔可夫决策过程

马尔可夫决策过程（MDP）就是**给强化学习问题建立的标准数学框架**。
如下图所示：
- **它由五元组构成**：状态 S、动作 A、转移概率 P、奖励 R、折扣 γ。
- **核心假设是马尔可夫性**：下一步只取决于当前状态和动作，与更早的历史无关。
- **它描述的是一个交互循环**：在状态 s 做动作 a → 环境给奖励 r、转到新状态 s' → 再决策。
- **它要解决的问题**：在这个过程里找到一个策略 π，让长期累积奖励最大。
- **Q 学习、TD、MC 等方法，本质上都是在 MDP 框架下求解最优策略的不同算法。**
下图中过程可以简化为序列：
$$
S_t,A_t,R_t,S_{t+1},A_{t+1},R_{t+1}....
$$
从当前到未来的总收益就是这些 $R_t$ 之和。但是为了避免收益爆炸，会用一个折扣系数降低未来收益的权重
![[attachments/Pasted image 20261013230558.png|316]]
### 贪婪跟探索
上面计算收益之和的时候，会出现一种情况，考虑下表的两种情况：
- 对于收益1，虽然总和收益更大，但是走第三步时带来的损失。
- 对于收益2总和收益虽然更小，但是每一步都是正收益。
如果训练的时候都是倾向于贪心算法（每一步都走收益最大的），那么模型就会走收益2。从而错过更好的收益1。因此训练的过程中也会引入探索，给模型一些发现更好路线的机会

| 收益1 | 1   | 1   | -2  | 10  |
| --- | --- | --- | --- | --- |
| 收益2 | 1   | 1   | 1   | 1   |

## 贝尔曼方程
贝尔曼方程是强化学习的数学基础，看起来很复杂，实际就是一个递推/自举方程，核心公式为：
$$V(s) = \mathbb{E}\big[r + \gamma V(s')\big]$$
其中$s'$为下一次的状态
**价值之间的自洽关系**：当前状态的价值，等于即时奖励加上未来价值的折扣期望。
### 直接用贝尔曼方程求解
几乎没有实际问题能用贝尔曼方程直接求解，主要问题有两个：
1. 有无限个状态（例如机器人走路），对应贝尔曼方程就是无限个，显然无法求解
2. 状态有限，但太多无法计算，例如围棋

对于书中3x4网格问题实际是可以用贝尔曼方程求解的（需要12个方程）
计算时**把贝尔曼方程写成线性方程组**：
对每个状态 s 列一个方程：
$$V(s) = \sum_a \pi(a|s)\sum_{s'} P(s'|s,a)\big[R + \gamma V(s')\big]$$
如果状态有 N 个，就有 **N 个方程、N 个未知数**，可以用矩阵直接解：
$$V = R + \gamma P V \quad\Rightarrow\quad V = (I - \gamma P)^{-1} R$$
### 无限状态时怎么办

- **函数逼近**：用网络代替表格（深度强化学习），参数有限，状态无限也能学
- **采样**：MC、TD 不去枚举所有状态，而是**走到的状态才更新**
- **只更新访问过的状态**：没到过的状态暂时不管

## 求解办法
前面提到了对很多问题不能用贝尔曼方程求解，其实还有很多其他方法求解。这里对应书中介绍的几种经典求解方法。
先总结下这几种方法的本质区别：

| 方法          | 更新目标用什么                  | 要不要环境模型<br>知道 P(s'\|s,a) 和 R | 要不要等回合结束 |
| ----------- | ------------------------ | ---------------------------- | -------- |
| 动态规划 DP     | 用**已知模型**算期望             | **要**                        | 不用（自举）   |
| 蒙特卡洛 MC     | 用**实际走完的真实回报**           | 不要                           | **要**    |
| TD 算法       | 用**走一步 + 自举估计**          | 不要                           | 不用       |
| Q 学习（TD 特例） | TD 的一种（off-policy + max） | 不要                           | 不用       |

### 动态规划 DP
动态规划这个名字起的不是很好，简单来说动态规划就是：**最优子结构 + 重叠子问题**（关于动态规划可以参考 [[../computer/《数学之美》读书笔记|《数学之美》读书笔记]] 中介绍的用动态规划做导航问题，从这里看，导航问题也可以归为强化学习问题）
它的前提是：
1. **最优子结构**：大问题的最优解，能由小问题的最优解拼出来
2. **重叠子问题**：同一个小问题会被反复用到

**在强化学习里，贝尔曼方程天然就是"最优子结构"：状态 s 的价值，由后继状态 s' 的价值决定**
$$V(s) = \mathbb{E}\big[r + \gamma V(s')\big]$$
**前提：知道环境模型（有格子问题的地图）**：知道在 s 做 a 会以多大概率到哪个 s'、拿多少奖励
**DP 的做法是（参考下式）：**
- 先假定 V(s') 已知（或上一轮的估计）
- 用它去更新 V(s)
- 反复迭代，直到所有 V 收敛
$$V(s) \leftarrow \sum_{a} \pi(a|s) \sum_{s'} P(s'|s,a)\big[R + \gamma V(s')\big]$$
**特点：** 拿到地图，直接算出来
- 对所有可能的下一个状态**求期望**，不是采样（蒙特卡罗是采样）
- **自举**（用 V(s') 更新 V(s)）
- 缺点：真实问题几乎拿不到模型（不知道确切的概率），且状态多时算不动
### 蒙特卡洛 MC
DP需要知道真实环境才能计算（对于一些电子游戏是可以的，但实际问题不太行）。
如果没有真实环境相关的知识，就没法知道：
**在状态s，执行动作a，有多大的概率得到s'**
这就造成没法计算每一步的收益。这个时候就需要蒙特卡洛模拟。简单说，蒙特卡洛就是随机试，试的次数多了，真实的分布就出来的。

**前提**：不需要模型，但要**和环境交互**（要试出来分布），而且**必须走完整个回合**。
**更新式：**
直观描述：用 估计出来的价值 $V(t)$ 跟试出来的 $G_t$ 之间的差值 来更新估计，为了稳定，需要一个学习率 $\alpha$
$$V(s) \leftarrow V(s) + \alpha\big[G_t - V(s)\big]$$
其中 $G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots$ 是**从这一步到回合结束的真实累积回报**。
**特点：** 亲自走完，看真实结果
- 目标是**真实值**，不是估计 → **无偏**
- 但必须等回合结束才能算 $G_t$
- 方差大（一整条轨迹的随机性全进来了）
- 只能用于**有终点的回合制任务**
### TD 算法

**前提**：不需要模型，**不用等回合结束**，走一步就能更新。

**更新式（TD(0)）：**

$$V(s) \leftarrow V(s) + \alpha\big[\underbrace{r + \gamma V(s')}_{\text{TD 目标}} - V(s)\big]$$

**特点：**

- 用**走一步的真实奖励 r + 对下一步的估计 V(s')** 当目标
- **自举** → 有偏，但方差小
- 每步都能学，在线学习
- 是 MC 和 DP 的折中

**和 MC 的直观对比：**

- MC：等整趟旅程结束，看总成绩
- TD：走一步就猜"我大概能拿多少"，用这个猜去修正

> 一句话：**走一步，边猜边学。**

### 4. Q 学习

Q 学习是 **TD 的一个特例**，专门学**动作价值 Q(s,a)**，而且是 **off-policy**：

$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]$$

**它的特殊性在于那个 `max`：**

- 更新时假设**下一步永远选最优动作**，不管实际走的是哪个
- 所以它学的是**最优策略**的价值，哪怕当前行为策略是在乱走
- 这叫 **off-policy**：行为策略和目标策略可以不同

对比 **SARSA**（on-policy 的 TD 控制）：

$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma Q(s',a') - Q(s,a)\big]$$

SARSA 用**实际下一步动作**的 Q，Q 学习用**最大**的 Q。区别就在这。

> 一句话：**TD 学价值，Q 学习用 TD 学"最优动作价值"，且敢用 max。**

## 五、偏置-方差 这个核心权衡

这是理解它们区别的**最关键视角**：

| | 偏置 | 方差 | 原因 |
|---|---|---|---|
| MC | 无偏 | 高 | 用真实回报，但一条轨迹随机性大 |
| TD | 有偏 | 低 | 自举引入偏差，但只看一步 |
| DP | 有偏 | 最低 | 直接求期望，但依赖模型正确 |

- **MC 准但抖**：样本足够多才收敛
- **TD 稳但可能偏**：靠自举，初期估计错会传下去
- **DP 最稳**：但要模型，且状态爆炸

---

## 六、一句话总结

> - **DP**：有模型，直接对下一步求期望
> - **MC**：没模型，走完整趟看真实总回报
> - **TD**：没模型，走一步用估计当目标（自举）
> - **Q 学习**：TD 的一种，学动作价值，用 max 做 off-policy
>
> 本质区别就两问：**要不要模型？未来是用真实值还是用估计？**
