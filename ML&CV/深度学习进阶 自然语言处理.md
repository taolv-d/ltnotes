# 网络出现之前——共现矩阵
早在深度学习应用前，自然语言处理的研究就已经开始了。
## 共现矩阵
**共现矩阵** 把词表示成向量，通过计算不同向量间 **余弦相似度**的方法计算挖掘词汇间的潜在关系。

简化例子：窗口只看前后各1个词，语料是“我 爱 自然 语言 处理”：

|      | 我 | 爱 | 自然 | 语言 | 处理 |
|------|----|----|------|------|------|
| 我   | 0  | 1  | 0    | 0    | 0    |
| 爱   | 1  | 0  | 1    | 0    | 0    |
| 自然 | 0  | 1  | 0    | 1    | 0    |
| 语言 | 0  | 0  | 1    | 0    | 1    |
| 处理 | 0  | 0  | 0    | 1    | 0    |

1. **词向量来源**：共现矩阵的行向量可以直接当作词的分布式表示。
2. **稀疏性**：词表很大，矩阵通常非常稀疏、维度很高。
3. **高频词干扰**：原始计数会被高频词主导（例如 "the"）—— 不用余弦相似度改用互相信息。
4. **降维**：常配合 SVD 等降维。
## 共现矩阵的问题
**SVD 压缩**
当处理的句子越来越长时，共现矩阵会以平方倍数增长，这造成共现矩阵的存储非常困难。一种解决办法就是降维（基于共现矩阵稀疏性），常见做法是奇异值分解（SVD）。
但是当共现矩阵大到一定程度时，SVD 压缩也变的不可行（计算、存储成本过高）。
此时就出现了基于网络来直接训练出 降维的共现矩阵

# word2vec
word2vec 跟我们现在常见的语言模型有区别。他实际是**利用网络训练的方法得到压缩的共现矩阵**（这里共现矩阵实际应该叫 分布表达式，保存在embedding 中）
由于word2vec 的目的是得到 压缩共现矩阵，因此训练使用的网络在训练完成就可以丢弃了。
## CBOW
CBOW 是word2vec 中的一个实现，下图是书中的例子，用句子“you say goodbye” 来训练，其中 you goodbye 作为输入，要预测的是 say。
网络最终的训练的产物时 输入embedding(即图中$W_{in}$ )
网络的运行方式如下：
1. 输入经过embeding 后转换为向量
2. 两个输入经过网络得到预测结果
3. 真值经过相同的embedding 转为为向量（这一步图中没有完整画出来）
4. 计算真值跟预测结果的交叉熵损失（这一步就是回归问题的通用框架了）

# 循环神经网络 RNN
RNN 引入了顺序的输入，更符合语言的特点。同时增加了记忆单元。
下图是RNN展开示意图，左侧是展开前，可以看到**RNN的输出会作为下一时刻的输入**，第一次这里输入0。

RNN 内部其实非常简单，就是一个权重+tanh激活
![[attachments/Pasted image 20261024230712.png|557]]
## RNN 的问题
梯度消失/爆炸
1. 激活函数 tanh: 反向传播时 tanh 会被反复调用，造成梯度会反复缩小。改成ReLU能够缓解（但是ReLU 小于0部分截断本身也会造成梯度消失）
2. 权重乘法部分：权重部分的反向传播（导数）是权重与激活值相乘。由于RNN会中有多次相乘的操作（**相当于对权重求n次方**）：
	1. 权重>1，连续相乘造成**梯度爆炸**——裁剪（限幅）
	2. 权重<1，连续相乘造成梯度消失——解决办法 Gated RNN
3. 记忆消失，记不住长距离的信息（梯度消失）

## LSTM
LSTM 长短期记忆网络，相比RNN增加了门控
![[attachments/Pasted image 20261024232000.png|491]]

**输入**：
*   $x_t$：当前时刻的输入数据
*   $h_{t-1}$：上一时刻传过来的**隐藏状态**（短期记忆）
*   $c_{t-1}$：上一时刻传过来的**细胞状态**（长期记忆）
**输出**：
*   $h_t$：当前时刻的**隐藏状态**，会传给下一个时刻，同时也会作为当前时刻的输出。
*   $c_t$：当前时刻更新后的**细胞状态**，继续沿着传送带传给下一时刻。
**门(从左到右三个$\sigma$)**:
1. 遗忘门：**忘记过去的哪些信息**, $f$ 输出 0，过去的记忆就被彻底遗忘。
2. 输入门：**要把当前的新信息存入多少到长期记忆中**，$g$ 是新知识，$i$ 是新知识的多少比例会被加入到记忆中
3. 输出门：**当前时刻要输出什么信息给下一个时刻$h_t$**，
	1.  刚刚更新好的 $c_t$经过 tanh 激活（把值压到 -1 到 1）。
	2.  输出门 $o$ 产生一个 0 到 1 的控制信号。
	3.  两者相乘得到了当前的**隐藏状态 $h_t$**（短期记忆）
