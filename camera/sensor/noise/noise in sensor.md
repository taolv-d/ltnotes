# 成像各阶段的噪声

![[attachments/Pasted image 20260516095519.png]]

结合上图分析下传感器拍摄一张图是各种阶段的噪声：

| 阶段              | 噪声来源                      | 说明                     |
| --------------- | ------------------------- | ---------------------- |
| **光电转换（光子→电荷）** | 光子散粒噪声（Photon Shot Noise） | 光的量子本性，服从泊松分布，**不可消除** |
|                 | 暗电流散粒噪声（Dark Shot Noise）  | 热生载流子，随温度指数上升          |
|                 | 暗电流FPN                    | 各像素暗电流不一致（固定图案噪声）      |
| **电荷转移（传输栅）**   | kTC噪声（复位噪声）               | 复位时浮动扩散点电容上的热噪声，CDS可消除 |
| **像素内放大（SF）**   | 1/f噪声                     | 沟道载流子俘获/释放，低频主导        |
|                 | 热噪声（Thermal）              | 沟道电阻热噪声                |
|                 | \( V_T \) 不匹配 → FPN       | 源跟随器阈值电压差异             |
| **列/行读出电路**     | 列FPN                      | 各列放大器偏置/增益不一致          |
|                 | kTC（采样保持电容）               | 若不用CDS会残留              |
|                 | 热噪声 + 1/f                 | 列放大器自身噪声               |
| **片上输出放大器**     | 热噪声 + 1/f                 | 额外增益级贡献                |
|                 | PRNU（含增益非均匀性）             | 全局增益不一致（CMOS中较少单独提）    |
| **ADC**         | 量化噪声                      | 有限位宽，LSB级别             |
|                 | kTC / 热 / 1/f             | ADC内部采样保持和比较器噪声        |
## reset
相机曝光前，需要先通过 reset 把上一帧的图像信号清理掉。但是 reset 时会引入 kTC 噪声，造成每次复位后电压都不一样。
CDS 双采样电路就是应对 reset 这个问题设计的。它采集两次电压：
1. 复位后，开始积分前，此时就是 reset 后的噪声 $N_{reset}$
2. 积分后读出信号，即 $S+N_{reset}$
3. 两次采样做差，减掉噪声
![[attachments/Pasted image 20260516095701.png|369]]

CDS 出现基本已经消除了复位噪声。不过CDS 本身也会引入少量噪声，不过强度更低，往往被忽略不计了。下图描述了CDS 引入的噪声
![[attachments/Pasted image 20260516095736.png|444]]
上图：关注 $V_{DD}-V_T$ 的曲线，阴影部分可以看到每次复位后的电压会**上下波动**，这就是复位引入的噪声。
下图：是在恒定光照（assuming constant illumination）下测量的CDS信号：
- 如果CDS 是完美的，数据就应该是图中的平直的虚线
- 实际的结果是有波动的曲线，说明CDS 本身也会引入少量采样时间噪声（始终抖动引起的采样时间误差）
## 光电转换
1. **光子散粒噪声**:来源于光子的量子本性，服从泊松分布。
	1. 参考[[光子散粒噪声都是泊松分布吗？]]
	2. 光子泊松分布的特性简化了很多噪声、信号的分析。很多测试标准都依赖这一条件。例如[[芝加哥大学：Noise DR Bit Depth in Digital SLRs]] [[../../evaluation/EMVA1288|EMVA1288]]
2. **暗电流散粒噪声**：热生载流子，随温度指数上升。一些噪声要求很高的场景（天文摄影、医疗等）会使用制冷相机来降低温度
3. **PRPN**：各像素暗电流不一致（固定图案噪声）
4. **FPN**: 固定噪声，例如坏点等
5. **DSNU**: 不同 pixel 对光信号的灵敏度差异等
# 噪声性质

| 类别                | 噪声                 | 特点               |
| ----------------- | ------------------ | ---------------- |
| **随机噪声（时间上变化）**   | 散粒噪声（光/暗）          | 泊松，与信号平方根相关      |
|                   | 热噪声（kTC）           | 白噪声，与电容相关        |
|                   | 1/f噪声              | 低频，功率谱 \( 1/f \) |
| **固定图案噪声（空间上不变）** | FPN（\( V_T \) 不匹配） | 行/列/像素固定偏移       |
|                   | PRNU               | 像素响应不一致（增益变化）    |
|                   | 暗电流FPN             | 暗信号非均匀           |
# 噪声影响
## 画质
显然噪声会影响成像的质量。但是相对直接能看到的早点外，还有很多间接影响（通常可以用SNR 来描述）：
- 影响 AE / AWB 算法的准确性，进一步影响最终的画质
- bayer 图中额噪声破话 RGB 之间的关系，影响画质
- 多帧堆叠时需要更多图像才能有较好的效果
## 动态范围
![[attachments/Pasted image 20260516095541.png]]

- 噪声直接决定了**噪底（read noise + dark noise）** 的高度。
- 如果噪声基底很高，暗部细节会被淹没，导致**实际可用动态范围远小于传感器标称值**。
- 后果：高动态场景（如逆光、夜景）中，要么亮部过曝，要么暗部死黑，后期无法拉回。

## 编码压缩效率（文件体积）
- 噪声本质是**高频随机信号**，在频域中分布广泛。
- 视频编码器（H.264/H.265）和图像编码器（JPEG/HEIC）依靠**空间/时域预测**来压缩数据。**噪声不可预测**，导致预测残差变大，熵编码效率急剧下降。
- 后果：**同样码率下，高噪声图像压缩后画质更差（块效应更明显）；同样画质下，文件体积大幅增加**（差2~3倍很常见）。
- 专业领域这叫**噪声的“码率税”**（bitrate tax）。

> 除了噪声，猛拉锐化放大噪声也会引入相似的表现

## 高级任务的影响
- 高级算法的精度
	- **边缘检测（Sobel/Canny）**：噪声会产生大量虚假边缘，导致后续特征提取失败。
	- **目标检测/识别（深度学习）**：虽然CNN有一定抗噪性，但在低光或远距离小目标场景下，**噪声会淹没有效特征**，导致漏检（false negative）或误检（false positive）。
	- **光流/运动估计**：噪声会破坏像素间的时域相关性，导致运动矢量计算错误。
	- **3D重建/立体匹配**：噪声会降低匹配代价函数的置信度，产生深度图空洞或错误深度。
- 科学/工业 测量结果等
## 人眼的视觉感知
- 噪声会**掩盖细节纹理**（如皮肤毛孔、布料纹理），让人感觉“模糊”或“不真实”。
- 暗部彩色噪声（红绿斑点）尤其令人不适，人眼对肤色区域的色噪极其敏感。
- 时域噪声（视频中的闪烁）会引发**视觉疲劳和头痛**，这在VR/AR头显中尤为严重（因为屏幕离眼近，时域噪声极易被感知）。
