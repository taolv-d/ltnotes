# 色差产生的原因
色差是镜头的像差之一，主要有两种表现^[https://zhuanlan.zhihu.com/p/151431106] ：

|          | 轴向色差                                                  | 横向色差                                                  |
| -------- | ----------------------------------------------------- | ----------------------------------------------------- |
| 原因       | 光轴上不同色光不能聚焦到同一点                                       | 镜头对不同色光的放大倍率不同                                        |
| 示意图      | ![[attachments/Pasted image 20260904234302.png\|338]] | ![[attachments/Pasted image 20260904234532.png\|257]] |
| 图像表现     | ![[attachments/Pasted image 20260904234607.png]]      | ![[attachments/Pasted image 20260904234616.png]]      |
| ISP 能否矫正 | 不能，随对焦距离变化                                            | 可以，根据放大倍率变化，缩放RGB三个通道                                 |
# 色差的标定
ISP 只能标定横向色差，即标定出 R G B 三个通道的缩放关系，然后ISP中缩放到同一的大小来避免色差。
镜头设计的时候也可以给出色差的补偿建议

标定可以用圆点图，或者棋盘格：
下图是拍摄的圆点图。如果分离RGB三通道，就可以看到三个通道中圆点稍微错位。计算出这个错位的偏移，就可以补偿色差。
