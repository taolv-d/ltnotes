# CFA 的分析与去马赛克算法
分析方向包括：空域、频域、时域、光谱四个方向
1. **为什么要用CFA 阵列？**：便宜，在CFA之前都是三个传感器，每个接收一个色光
2. **CFA 设计的原则**
	  1. 色彩空间
	  2. 排列方式（理论上随机排列能够避免顺序排列引入的artifices 但算法复杂）
3. **当前常见的CFA 存在的问题**
	1. 首先作者通过频域分析，发现CFA 是将亮度信号作为低频，将色差信号调制到了水平和垂直方向。但水平垂直方向是自然图像中能量最集中的部分，造成**亮度信号与色差信号混叠**，因此无法很好的还原出真实信号。
	  2. 这也是为什么去马赛克算法都会引入非线性操作来加强边缘
	  3. 作者设计了一个特殊的CFA阵列，让色差信号均匀分布在高频，且避开水平垂直方向（即不使用RGB滤光片，而是其他颜色，每一个通道可以看成是RGB 三个分量不同权重的和）
	  4. 作者的方法与现代算法之间的关系（如下表，虽然没有应用）

| 核心思想   | 作者频域方法                          | 现代ISP方法                                             |
| ------ | ------------------------------- | --------------------------------------------------- |
| 先重建G通道 | G通道采样率最高，承载了主要的亮度信息，且与R/B通道高频相似 | 一致                                                  |
| 利用色差   | 在频域中表现为调制到高频的色差信号（R-G, B-G）     | 在空间域中体现为对色差（G-R, G-B）进行插值，而非直接插值R、B。这是所有基于色差方法的共同基础 |
| 边缘导向插值 | 自适应地选择混叠更小的方向（水平或垂直）进行重建        | 一致。                                                 |
5. **为什么NN demoniac表现更好**
     1. **更强的模型**：非线性+多层结构，表达能力远超线性模型。
     2. **更大的视野**：全局感受野，能够利用远距离的上下文信息；传统算法通常是局部区域。
     3. **更深的特征**：自动学习从低级到高级的多层级特征，综合利用它们进行重建。
     4. **更好的训练**：端到端联合优化，用海量数据驱动数千万参数的学习。
6. **bayer有缺陷，为什么还在流行？**
	1. 三原色基于人类的视觉系统，这样设计符合直觉
	2. 技术惯性，太多设备、算法适配了，很难替代
	3. 从RGGB格式重建彩色的信号算法并不复杂（虽然不是最优）
7. 彩色ISP 中CFA 是非常核心的模块，以至于其他模块是放在其前还是后也需要考虑。
	1. 显然放在CFA前能够节省计算量，但误差可能会被CFA放大，甚至出现artifacts
	2. 不过现代ISP的pipeline设计都基本一致，估计已经是衡量效果与成本的最优结果了

# CFA 与噪声
 - CFA 改变了噪声分布，因此在CFA过程中降噪是比较好的方案（书中花了一章介绍，但是raw域降噪已经是常规手段了，因此不多展开）
 - 对于彩色噪声，有可能完全消除；对于亮度噪声，基本不可能完全消除
## 噪声+CFA的频域建模
1. 频域中图像 = 亮度信息+色差信息+噪声
2. 如果这三个信号分量在频域完全不重叠会能否完美去噪？
    1. 理论层面：如果“完全不重叠”且有理想滤波器，可以完美恢复。
	2. 实际情况：
	     - “完全不重叠”本身就不成立——亮度信号的频谱是无限宽的。
	     - 理想滤波器不存在——物理可实现滤波器都有过渡带。
	     - 采样带来的频谱复制——这是由离散采样这个行为本身决定的，无法改变。

# 白平衡
白平衡是一个典型的病态问题：
- 已知：最终图像的RGB值。
- 未知：光源的颜色 + 物体本身的反射率。
从一张图像中分离出这两个因素，本身就是高度不确定的（如何区分“一个红色的物体在白色光源下”和“一个白色的物体在红色光源下”）。因此，AWB算法都必须有先验输入（如何找到灰色）。
# 如何从连续的低质量的CFA数据重建高质量的图像（19章）
**问题的定义**：我们有一个低分辨率（LR）的CFA视频序列 ，目标是重建出一个高分辨率（HR）的彩色视频这个问题的挑战在于，它同时包含了三个子问题：**去马赛克、超分辨率、运动估计**

**分步计算效果差**
分步方案为：
1. 先对每一帧做去马赛克，得到低分辨率彩色图像序列。
2. 再对彩色图像序列做超分辨率，得到高分辨率彩色视频。
但这种方法效果不好，原因在于：第一步去马赛克的误差会被第二步超分辨率放大。分开处理时，两个步骤的模型假设可能不一致，导致**误差累积**。
## 本书的解法
**前向成像模型**
![[attachments/single-sensor-imaging-image-2.png]]

模型将所有退化因素统一到一个数学模型中。重建就是逆向求解问题。
这个模型告诉我们：我们观测到的低分辨率马赛克图像，是理想高分辨率图像经过运动、模糊、下采样、CFA采样和噪声污染后的结果。

**求解方法**
1. 联合MAP估计（最完整，但最复杂）
	1. 核心思想：建立统一的代价函数，包含数据保真项和多个先验约束项，迭代优化求解。
	2. 优点：理论上最完备。
	3. 缺点：计算量巨大，无法实时。
2. 两步法（Fast Implementation） 这里不展开了
3. 动态处理（Kalman Filter）
	1. 核心思想：对于视频序列，引入卡尔曼滤波进行递归处理。利用上一帧的高分辨率结果，预测当前帧的初始值。并用当前的实际值修正预测模型（这里是卡尔曼滤波的基本操作）
	2. 优点：适合实时视频处理，计算效率高。
	3. 缺点：卡尔曼滤波的模型假设（线性、高斯）可能与真实情况有偏差。
