# 鱼眼投影模型
鱼眼相机成像模型近似为单位球面投影模型。
鱼眼镜头主要存在径向畸变
一般将鱼眼相机成像过程分解成两步：先将三维空间点线性的投影到虚拟单位球面上；随后将单位球面上的点投影到图像平面上，这个过程是非线性的。

![](https://pic4.zhimg.com/v2-1acd4456620be2a0caae8b2c9cc131d9_1440w.jpg)

## 针孔投影模型

| 投影模型 | 公式                           |                                                                                                                                                                                  |
| ---- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 针孔   | $r_d=f\tan\theta$            | 相似性投影模型，其满足物点、成像中心、像点的共线关系![](https://pic2.zhimg.com/v2-54e5d7718aaf92eaa0e8e407aa7394f3_1440w.jpg)                                                                              |
| 等距   | $r_d=f\theta$                | ![332](https://pic2.zhimg.com/v2-7c6dd9ebb50018889bf163b6d4874281_1440w.jpg)                                                                                                     |
| 等立体角 | $r_d=2f\sin\frac{\theta}{2}$ | 等立体角的特点是相等立体角的入射面会产生相等面积的像，<br>其畸变程度介于等距模型与正交模型之间<br>![](https://pic4.zhimg.com/v2-6076093f0a80b279adb1fb76d971fc11_1440w.jpg)                                                   |
| 正交   | $r_d=f\sin\theta$            | 正交投影模型的畸变很大，近180度处的图像信息几乎全部丢失，且180度之外的场景区域将无法进行描述<br>![](https://pic3.zhimg.com/v2-74a479a48d5dde5848488445fc7ec528_1440w.jpg)                                                   |
| 体视   | $r_d=2f\tan\frac{\theta}{2}$ | 体视模型相比之下畸变最小，球形物面上的微小面元经过体视投影后，其像仍然是一个小圆。所以体视投影对微小物体成像有相似性。但正是这种成像的相似性，使得该投影方式不能提供足够的桶形畸变，影响成像视场<br>![342](https://pic2.zhimg.com/v2-27b8f2d971fb1d9b859f19f773f62b99_1440w.jpg) |

## 通用鱼眼相机模型-Kannala-Brandt 模型
Kannala-Brandt 提出了一种鱼眼相机的一般多项式近似模型。通过前面四个模型，可以发现 $\theta_d$ 是 $\theta$ 的奇函数，将这些式子按泰勒级数展开，发现 $\theta_d$ 用 $\theta$ 的次多项式表示，即
$$
\theta_d=k_0\theta+k_1\theta^3+k_2\theta^5+\cdots
$$
OpenCV中鱼眼相机标定方法就是KB模型。
